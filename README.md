# 世田谷パドレス 個人成績アプリ ⚾

草野球チーム「世田谷パドレス」の個人成績を記録・集計するWebアプリです。
チーム名の由来である MLB サンディエゴ・パドレスのブラウン & ゴールドをテーマにしています。

## 使い方

ビルド不要の静的Webアプリです。

- **ローカルで開く**: `index.html` をブラウザで開くだけで動作します
- **サーバーで公開**: GitHub Pages などにそのまま置けます
  （例: `python3 -m http.server` でローカル配信）

データは既定でブラウザの localStorage に保存されます（端末ごとに独立）。
チーム全員で同じデータを共有したい場合は、下の「チーム共有」を設定してください。
「設定・データ」タブから JSON 書き出し / 読み込みでバックアップができ、
打撃・投手成績は CSV 出力にも対応しています。
まず動きを見たい場合は「設定・データ」タブの **サンプルデータを読み込む** をお試しください。

## チーム共有（スプレッドシート連携）

Google スプレッドシートをチーム共通の保存先にすると、**誰が入力しても全員に反映**されます。
仕組み: アプリ → Apps Script ウェブアプリ → スプレッドシート（`players` / `games` / `batting` / `pitching` シートに1行1レコードで保存）。

### セットアップ（チームで1回だけ・管理者のGoogleアカウントで）

1. <https://sheets.new> で空のスプレッドシートを作成
2. メニュー「拡張機能」→「Apps Script」を開き、[`apps-script/Code.gs`](apps-script/Code.gs) の内容を丸ごと貼り付けて保存
3. 冒頭の `TOKEN = "padres"` を好きな合言葉に変更
4. 「デプロイ」→「新しいデプロイ」→ 種類「**ウェブアプリ**」
   - 次のユーザーとして実行: **自分** ／ アクセスできるユーザー: **全員**
   - 初回は権限の承認を求められます
5. 発行された「ウェブアプリのURL」と合言葉を、アプリの「設定・データ」→「チーム共有」に入力して接続
6. 接続後に表示される「**共有用リンクをコピー**」をLINEなどでチームメイトに送る
   → 受け取った人はリンクを開くだけで同じ共有データに接続されます

### 動作と注意

- 入力・削除のたびに項目単位で書き込むので、複数人が同時に別の試合を入力しても消し合いません（同じ項目を同時編集した場合のみ後勝ち）
- 圏外などで送信に失敗した変更は端末内に退避し、電波復帰後に自動再送されます（ヘッダーの「共有」チップで状態を確認可能）
- スプレッドシートを直接編集してもOK（次の同期で全員に反映されます）
- ウェブアプリのURLと合言葉を知っている人は誰でも読み書きできます。チーム内だけで共有してください
- コード（Code.gs）を修正した場合は「デプロイを管理」から**新バージョンとして再デプロイ**が必要です

### 接続エラーになるとき

- **入力するURLは「ウェブアプリのURL」**（`https://script.google.com/macros/s/…/exec`）です。スプレッドシートのURL（docs.google.com/…）や、Apps Scriptエディタ画面のURL、`…/dev` のURLでは接続できません
- デプロイ設定が「次のユーザーとして実行: **自分**」「アクセスできるユーザー: **全員**」になっているか確認してください（「Googleアカウントを持つ全員」でも不可）
- 確認方法: ブラウザのアドレス欄に `ウェブアプリのURL?token=合言葉&action=all` を貼って開き、`{"ok":true,…}` と表示されれば設定は正しいです（Googleのログイン画面が出る場合はアクセス設定が「全員」になっていません）
- 「合言葉が違います」と出る場合は、Code.gs の `TOKEN` の値とアプリに入力した合言葉が一致しているか確認してください（変更後は新バージョンとして再デプロイが必要）

### 再デプロイが反映されたかの確認

接続中は「設定・データ」→「チーム共有」に **Code.gs 版数** が表示されます。
`（最新）`と出ていれば貼り替え・再デプロイは反映済みです。古い版数や「旧」と出る場合は、
Apps Scriptに最新の `Code.gs` を貼って**保存**し、「デプロイを管理」→鉛筆→バージョン「**新バージョン**」で再デプロイしてください
（デプロイはその時点のコードを固定して動くため、貼り付けただけでは反映されません）。

## さざんかリーグ 順位表シミュレーター（単体ページ）

`league.html` は成績アプリとは独立した単体ページです（`index.html` とは連携しません）。

- 2026年9月2日時点の順位表を内蔵（勝点順・勝3点/分1点/敗0点、同勝点は同順位）
- 残り6試合の結果を入れると順位表がリアルタイムに更新
- **パドレスがプレーオフ（上位4）に入るために必要な勝敗**を、他チームの結果を全通り探索して判定
  （「最悪」＝他が最も不利に転んだ場合の順位。最悪でも4位以内かつ同勝点で並ぶ相手がいなければ**確定**）
- **得失点差のタイブレークに対応**。スコアを入力すると得失点差に反映され、
  同勝点で進出枠を争う相手が現れると、必要な点差を自動で提示します
- 入力結果はブラウザに保存されます

## 機能

- **選手管理** — 背番号・ポジション・投打・在籍状況
- **試合ごとの成績入力** — 試合(日付・相手・スコア)を登録し、選手ごとに打撃・投手成績を入力
- **シーズン切替** — 年度ごと / 全期間で集計
- **ダッシュボード** — チームサマリー、打撃・投手リーダーボード(規定打席/規定投球回対応)
- **ソート可能な成績テーブル** — 基本 / アドバンスト表示切替

## 収録指標

### 打撃
試合・打席・打数・得点・安打・二塁打・三塁打・本塁打・塁打・打点・盗塁・盗塁死・四球・死球・三振・犠打・犠飛・併殺打

**レート/セイバー系**: 打率 / 出塁率 / 長打率 / OPS / ISO / BABIP / BB% / K% / BB/K / 盗塁成功率 / **wOBA / wRAA / wRC / wRC+ / OPS+**

### 投手
登板・先発・勝・敗・セーブ・ホールド・投球回・対戦打者・被安打・被本塁打・与四球・与死球・奪三振・失点・自責点

**レート/セイバー系**: 防御率(9回/7回換算切替) / WHIP / K/9 / BB/9 / HR/9 / K% / BB% / **K-BB%** / K/BB / 被打率 / **FIP** / LOB% / 勝率

> リーグ全体のデータが存在しないため、wRC+ / OPS+ / FIP定数は「チーム全体をリーグとみなした」チーム基準(=100)の相対値として算出しています。wOBA係数は FanGraphs 公表の近年係数を使用。

```
apps-script/Code.gs … 共有バックエンド(Google Apps Scriptに貼り付けて使用)
fonts/              … 同梱Webフォント(Graduate / Oswald, latinサブセット)
```
