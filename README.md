# 世田谷パドレス 個人成績アプリ ⚾

草野球チーム「世田谷パドレス」の個人成績を記録・集計するWebアプリです。
チーム名の由来である MLB サンディエゴ・パドレスのブラウン & ゴールドをテーマにしています。

## 使い方

ビルド不要の静的Webアプリです。

- **ローカルで開く**: `index.html` をブラウザで開くだけで動作します
- **サーバーで公開**: GitHub Pages などにそのまま置けます
  （例: `python3 -m http.server` でローカル配信）

データはブラウザの localStorage に保存されます。
「設定・データ」タブから JSON 書き出し / 読み込みでバックアップやチーム内共有ができ、
打撃・投手成績は CSV 出力にも対応しています。
まず動きを見たい場合は「設定・データ」タブの **サンプルデータを読み込む** をお試しください。

## 機能

- **選手管理** — 背番号・ポジション・投打・在籍状況
- **試合ごとの成績入力** — 試合(日付・相手・スコア)を登録し、選手ごとに打撃・投手成績を入力
- **シーズン切替** — 年度ごと / 全期間で集計
- **ダッシュボード** — チームサマリー、打撃・投手リーダーボード(規定打席/規定投球回対応)
- **ソート可能な成績テーブル** — 基本 / アドバンスト表示切替

## 収録指標

### 打撃
試合・打席・打数・得点・安打・二塁打・三塁打・本塁打・塁打・打点・盗塁・盗塁死・四球・死球・三振・犠打・犠飛・併殺打

**レート/セイバー系**: 打率 / 出塁率 / 長打率 / OPS / ISO / BABIP / BB% / K% / BB/K / 盗塁成功率 / **wOBA / wRAA / wRC / wRC+ / OPS+**

### 投手
登板・先発・勝・敗・セーブ・ホールド・投球回・対戦打者・被安打・被本塁打・与四球・与死球・奪三振・失点・自責点

**レート/セイバー系**: 防御率(9回/7回換算切替) / WHIP / K/9 / BB/9 / HR/9 / K% / BB% / **K-BB%** / K/BB / 被打率 / **FIP** / LOB% / 勝率

> リーグ全体のデータが存在しないため、wRC+ / OPS+ / FIP定数は「チーム全体をリーグとみなした」チーム基準(=100)の相対値として算出しています。wOBA係数は FanGraphs 公表の近年係数を使用。
